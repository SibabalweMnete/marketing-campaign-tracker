## 🚀 Command Quick Reference

### Setup
```bash
python3 main.py --init      # Initialize database
python3 main.py --collect   # Collect campaign data
```

### View & Monitor
```bash
python3 main.py --summary   # Quick portfolio snapshot
python3 main.py --dashboard # Live real-time dashboard
```

### Analysis & Reports
```bash
python3 main.py --report    # Full report + CSV + JSON
python3 main.py --insights  # Get recommendations
python3 main.py --compare   # Compare campaigns
python3 main.py --channels  # Channel analysis
python3 main.py --efficiency # Cost metrics
```

### Automation
```bash
python3 main.py --auto      # Do everything at once
```
